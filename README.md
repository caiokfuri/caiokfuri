### 💡 About Me

I'm [Caio](https://github.com/caiokfuri) (or **Kfuri** to friends), a Software Engineer based in Brazil. 

Currently, I work across the stack with **Java (Spring Boot)**, **C++**, and **React**. I care deeply about keeping things organized, writing clean and scalable code, and understanding how computers actually work under the hood. 

My goal is to grow as an engineer by building software that lasts — creating solid applications that genuinely make a positive difference in people's lives. In my daily workflow, I rely on tools like **Docker**, pair with AI workflows via **Claude Code** and **Antigravity**, and often sketch out ideas on my tablet before turning them into code.

Always glad to connect, talk tech, or collaborate on meaningful projects!
